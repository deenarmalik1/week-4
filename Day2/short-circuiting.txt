Short-Circuiting in JavaScript - Logical Operators:

Short-circuiting means JavaScript does not evaluate the second operand if the result is already determined by the first operand.

1. Logical OR `||`:

`||` looks for the first truthy value.

It works like this: It evaluates left to right. If first operand is truthy, it returns the first operand immediately and does not even look at second operand. If first operand is falsy, it returns the second operand.

Because of this, `||` was traditionally used to set default values. If left side is falsy like null, undefined, 0, empty string, then we should the right side as fallback.

But drawback is it treats all falsy values same, so 0 or "" also triggers fallback even if we wanted to keep them.

Short-circuit effect: If we have function call on right side, it will not be called if left side is truthy.

2. Logical AND `&&`:

`&&` looks for the first falsy value.

It evaluates left to right. If first operand is falsy, it returns first operand immediately without evaluating second. If first operand is truthy, it returns second operand.

Main use is guarded execution or conditional rendering. Instead of if statement, we say first condition must be truthy, then only second part executes.

Short-circuit effect: Right side function only runs if left side is truthy. This is used to avoid errors, like checking if object exists before accessing its property.

Important Concept - Return Value:

Both `||` and `&&` do not necessarily return boolean. They return the actual operand value that decided the result. That's why they are useful for assignment.

`||` returns first truthy or last falsy.
`&&` returns first falsy or last truthy.

Falsy Values in JS: false, 0, -0, 0n, "", null, undefined, NaN. Everything else is truthy
